# GRC 102 – Security Policies & Procedures

##  Project Overview

This project was completed as part of my "GRC 102 Practical Laboratory" and focused on developing a practical information security policy framework for a growing technology company, "NexusTech Solutions".

The project addressed the challenges caused by an outdated IT Rules document by separating security requirements into clear policies, standards, guidelines, and procedures.

##  Objectives

* Establish a clear security policy hierarchy
* Develop an "Acceptable Use Policy (AUP)"
* Create a formal "User Access Request Procedure"
* Develop a policy communication and training plan
* Define an approach for policy review and maintenance

##  Skills Demonstrated

* Information Security Governance
* Policy & Procedure Development
* Access Control & Least Privilege
* Security Awareness & Training
* Policy Compliance & Enforcement
* Risk-Based Policy Review
* GRC Documentation

##  Frameworks Referenced

* ISO/IEC 27001:2022
* ISO/IEC 27002:2022
* NIST Cybersecurity Framework (CSF) 2.0

##  Project Outcome

The project shows how security requirements can be translated into clear, practical, and maintainable governance processes.
